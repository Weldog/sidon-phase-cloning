# Paper 3 — Exact Optimal Cloning of Stabilizer States

Michael Weldon (ORCID 0009-0001-6119-0560), October 2026. Preprint on Zenodo: https://doi.org/10.5281/zenodo.23462235 (all versions).

- `Weldon_2026_Exact_optimal_cloning_of_stabilizer_states.pdf` — the paper
- `main3.tex`, `refs3.bib`, `main3.bbl` — LaTeX source
- `code/` — certificate scripts and outputs, and an independent implementation of the argument (see `code/README.md`)

Main result: for uniform n-qubit stabilizer states, the optimal T→T+k cloning fidelity (T ≤ 3, any k, any n) is
C(2^n+T−1, T)·F_{T+k−κ(k)}, where F_s is the stabilizer frame potential and κ(k) is the largest dimension of a
doubly-even binary code of length k.
