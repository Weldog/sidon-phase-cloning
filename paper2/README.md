# Paper 2 — Universal Cloning Is Optimal Exactly for Designs

Michael Weldon · Independent Researcher · ORCID 0009-0001-6119-0560 · Version 1, 18 October 2026

Theorem: for every probability measure on pure states and all T, k ≥ 1, the optimal average global fidelity of T→T+k
cloning equals Werner's universal value D_T/D_{T+k} if and only if the measure is a complex projective (T+k)-design.
Corollaries: stabilizer states (any number of qubits) T+k ≤ 3; SICs T+k ≤ 2; complete MUBs T+k ≤ 3 (d=2), ≤ 2 (d≥3).
